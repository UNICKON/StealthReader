# 隐形背诵：Anki 复习长在阅读窗口里 — 设计

- 日期：2026-10-15
- 状态：待确认（确认后才写代码）
- 前置：Anki 里安装 AnkiConnect 插件（工具 → 插件 → 获取插件 → `2055492159` → 重启 Anki）

## 1. 为什么

工位上背东西时，屏幕上不能出现 Anki 那个界面。已有的阅读器本来就是为"看着像在读文档"造的
（透明底、变色龙、防截图、一键隐形、安全文档兜底），把复习界面长在它里面，背诵就自动继承了
这一整套伪装，不用再做一个"能隐身的 Anki"。

实测过的目标场景：`Ctrl+Alt+A` 显示卡片 → 背 → `Ctrl+D` 收起 → 继续干活。

## 2. 和阅读器的关系：两层模型

阅读器现在已经是两层，本次只把"内容层"从两种变三种，**可见性层一个字节不改**：

| | 内容层（互斥；切换一律"快照 → 换内容 → 还原"） | 可见性层（不认识内容是什么） |
|---|---|---|
| 现在 | 书页 / 安全文档 | 显示 · 隐藏（`Ctrl+D`）· 偷瞄（`Ctrl+E`）· 防截图 · 透明/变色龙 · 排版 |
| 加完 | 书页 / 安全文档 / **卡片** | 同上 |

因此"支持现有 cd/ce 等等"不需要加特例，靠分层自动成立：

| 按键 | 在背诵里的含义 |
|---|---|
| `Ctrl+D` | 隐藏窗口。**不退出背诵**，叫回来还是同一张卡（这也是"要打字就先收起来"的开关） |
| `Ctrl+Alt+D` | 换成安全文档（有人来了）。切回来**还是同一张卡** |
| `Ctrl+E` | 保持"看书的偷瞄"语义：先退出背诵回书，再浮现书页 |
| `Ctrl+Alt+A` | 进/出背诵（窗口可见时再按一次 = 退出） |

实现上**复用**（不复制）今天刚硬化的那套：安全文档的 `snapshot_book_state()` /
`restore_book_state()`（本次把它从安全文档里抽成公用函数）、`apply_style()` 的排版套用、
`record_view_position()` 与 `scroll_page()` 的"禁写进度"守卫、`GlobalInputHook` 的吞键框架。

## 3. 数据边界（最要紧的一条）

- **只走 AnkiConnect**（HTTP `127.0.0.1:8765`），**绝不读写 `collection.anki2`**。
  排程、撤销、每日上限、学习步骤、leech、AnkiWeb 同步全部归 Anki。
- 走"**镜像 Anki 自己的复习器**"这条路：用 `guiDeckReview` 让 Anki 自己开着这个牌组的复习，
  我们只把"当前这张卡"（Anki 已渲染好的正/反面 HTML）取过来画在自己窗口里；评分时把
  1/2/3/4 交回 `guiAnswerCard`。**所有 SRS 语义都在 Anki 里发生**，我们只是另一块显示屏。
- 图片/音频直接从 `collection.media` 读文件（26,730 个文件、452 MB，不走 base64 传输）。
- 本次开局为了摸底只读扫过一次库结构（`mode=ro&immutable=1`），之后不再碰。

## 3.5 本机实测校正（批次 1 探针，24/24）

计划里的假设有几条被真机推翻了，以实测为准：

1. **AnkiConnect 的实参必须嵌在 `params` 里**。扁平写法（`findCards` 直接把 `query` 放顶层）
   会被**静默忽略**：返回空列表、`getDeckStats` 报 "missing 1 required positional argument"。
2. **`guiCurrentCard` 的 `answer` 在没翻面时就已经渲染好了**（实测 2,124 / 2,377 字符），
   所以"现在显示正面还是反面"不能靠 `answer == ""` 判断，**由我们自己记状态**——我们只有一个
   输入口，而且进入背诵会把 Anki 窗口收起来，这个状态是可靠的。
3. **本机有代理会插手 localhost**：对任何未监听端口都回 `HTTP 502 Bad Gateway`。客户端必须
   **显式禁用代理**（`ProxyHandler({})`）——否则一是连不上时错误分类走偏，二是**卡片内容可能
   经过第三方**。
4. **选父牌组 = 复习整棵子树**（实测选 `背诵` 抽到的是 `背诵::诗句::古诗十九首` 的卡）。
5. **Anki 最小化时 AnkiConnect 的 GUI 动作照常可用**，`guiDeckReview` 甚至不会把它拉起来。
   所以"收起来"不妨碍复习；进入背诵时那句最小化只是安全网（用户没最小化时兜一下），
   本来就最小化就不动它、退出也不还原。
6. **你的媒体库里没有一张图片**：26,730 个文件 = 25,899 mp3 + 828 m4a + 3 otf（自定义字体）。
   也就是说这几副牌是**纯音频卡**——音频不是"锦上添花"，是主体（`<img>` 支持照样留着，成本极低）。
   卡片自带的 `@font-face` 字体我们不去加载（`<style>` 整块会被剥掉），卡片用阅读器自己的字体渲染。
7. 卡片 HTML **开头就是一大段 `<style>`**（实测 2,124 字符里大半是 CSS），所以简化器第一件事
   就是把这整块剥掉。
8. 计数器改用 **`getDeckStats`**（Anki 按每日上限算好的 new/learn/review），比 `findCards` 现算
   更贴近"今天还欠几张"，也省掉一次可能返回两万多个 id 的查询（`findCards('*')` 实测 29,646 个 id）。

## 3.6 评审后的接口契约修正（又一轮真机核实，覆盖上文相应条目）

独立评审（读了 AnkiConnect 源码 + Anki 官方手册）提了一批修正，我逐条在真机上核实后采纳：

1. **藏 Anki 用 `SW_HIDE`，不是最小化**。实测：`SW_HIDE` 之后 AnkiConnect 的 GUI 动作照常可用
   （`guiCurrentCard` 还能取到同一张卡），而隐藏的窗口**不进 Alt+Tab、没有任务栏图标、悬停也
   没有缩略图**。最小化做不到这一点——最小化的窗口会被人从身后按 Alt+Tab 看到最后那一帧，
   也就是那张卡。**所以 §4 那条"最小化"改成"藏起来"**，退出还原用 `SW_SHOWNOACTIVATE`，
   **绝不激活**（`SW_RESTORE` 会把 Anki 亮到最前面，正好把假文档暴露给同事）。
2. **音频与计时交给 Anki 自己**：`guiPlayAudio()`（播当前这一面的音频，`[sound:]`、`{{tts:}}`、
   自动播放策略它都懂）与 `guiStartCardTimer()`（让答题用时准确）。原计划自建 `[sound:]` 抽取 +
   QtMultimedia/MCI 是重复劳动且更弱，删掉。
3. **评分键以 `buttons` 为准**：Anki 学习步/FSRS 下可能只给 2 个按钮，此时按 4 会
   **静默 `return False`**。`answer()` 必须把 False 当"未生效"处理并提示，**不能当成功继续前进**。
4. **评分是异步的**：`guiAnswerCard` 只表示"开始了"，紧跟一次 `guiCurrentCard` 会读到还没翻过去的
   那张（cardId 相同还能骗过一致性校验）。所以评分+取下一张走 `multi` 链式调用等最终态。
5. **卡片渲染三处收紧**：剥掉 `<style>` **和卡片里的内联 `font-size` / `<font>`**（否则字号设置
   时灵时不灵）；Anki 返回的 `css`（实测 1,967 字符）过滤掉字号/字体/定位后塞进
   `setDefaultStyleSheet()`（保留颜色、居中、表格，卡片才"像文档"）；建**卡型白名单**，
   不支持的卡型（JS/Image Occlusion/打字作答/MathJax）明确提示"该卡型不支持隐形显示"——
   空白比走样更可疑。
6. **计数一律取 Anki**（`getDeckStats` + `getNumCardsReviewedToday`），不用本地内存计数。
7. **头号风险从"最小化不工作"换成"Anki 忙"**：Anki 同步/媒体检查/导入/查库时会把**所有 `gui*`**
   拦下（`busy:`）。首次同步 452 MB 媒体可能几分钟，这段时间窗口看起来就是坏的。
   对策：状态行显示"Anki 正在同步"、退避重试、**绝不静默吞掉用户的评分**。
   （原 §8 的"最小化时 API 不工作"是无依据的担心，实测不成立，删掉。）
8. **对账**：用户可能跑去 Anki 自己窗口答题（或插件 veto），我们窗口会显示旧卡。窗口可见时
   低频（2–3 秒）轮询核对，不一致就重渲染并提示。
9. **apiKey 与切换配置档**：AnkiConnect 若配了 `apiKey`，请求要带 `key`；在 Anki 里切档后
   cardId 全部失效——检测到就优雅退出背诵，而不是抛原始异常。
10. **守卫改成一个判定**：不再逐点加 `review_mode`，而是引入 `_book_veiled() = safe_mode or
    review_mode`，替换 `main.py` 里 16 处 `safe_mode` 判断。其中两处**会损坏数据**，必须覆盖：
    `apply_highlight_selections`（3339，会把书页高亮画到卡片上）与 viewport 鼠标命中
    （3654，会把卡片文字按卡片偏移写进这本书的划线存档）。
11. **隐私**：卡片正文、答案、音频文件名一律不进 `stealthreader.log`、不进探针输出。
12. **吞键**：加设置开关（默认开）；判据是"窗口可见**且未最小化**"。代价说清楚：窗口亮着时
    space/回车/1-4/U/R/Esc 会被吞，想正常打字就先 `Ctrl+D` 收起。
13. **§5 那四条跨模式承诺要在专门一批里实现**（原计划四个批次里一条都没落）。

## 4. 界面与键位

- 卡片渲染进现有的 `text_edit`：Anki 的 HTML 先做**简化**（去掉 `<script>/<style>`，
  保留 `b/i/u/br/div/p/span/img/table`，`[sound:x.mp3]` 抽出来播放并从正文里去掉，
  `class="cloze"` 映射成加粗+高亮），然后 `document().setBaseUrl(collection.media)` 让
  `<img src="x.jpg">` 直接能加载。
- **卡片排版独立于书籍排版**：居中、不首行缩进、不两端对齐、正常行距，只沿用阅读字号
  （等比缩放）和页边距；页边距只留白，不做按页收边。
- 顶部一行状态：`牌组 · 待复习 N · 本次已背 M`；Anki 今日清完时显示"今日已清"。
- 键位（**只在窗口可见时**生效，且全局吞掉，不会漏进背后正在编辑的文档）：
  空格/回车 = 显示答案，`1/2/3/4` = 重来/困难/良好/简单，`U` = 撤销，`R` = 重播音频，
  `Esc` = 退出背诵。要正常打字就先 `Ctrl+D` 收起（和偷瞄里滚轮只在偷瞄时被吞是同一个约定）。
- 滚轮在背诵里是**滚动卡片**，不翻书页。
- 进入背诵时把 Anki 自己的窗口最小化（找不到窗口就保持原样）、退出时还原——否则同一个答案
  会明晃晃地显示在旁边的 Anki 窗口里，伪装就白做了。

## 5. 状态机

```
                  Ctrl+Alt+A                     Ctrl+D / Ctrl+D
   书页 ⇄ 卡片            （互斥，切换都先 exit 再 enter）
   书页 ⇄ 安全文档
   卡片 → Ctrl+Alt+D → 安全文档 → Ctrl+Alt+D → 卡片（同一张，重新渲染）
   卡片 → Ctrl+E → 退出背诵 → 书页的偷瞄
   安全文档 → Ctrl+Alt+A → 退出安全文档 → 卡片
```
- 进入卡片时快照一次书的状态（页首 + 视口顶那一行）；退出背诵时按快照还回去，
  **精确到字**，并且这一路**不写 `last_local_pos`**（与安全文档同一道闸门）。
- 背诵会话（牌组、卡 id、是否已翻面）在内存里活着，所以 `Ctrl+Alt+D` 来回切之后仍是同一张卡；
  退出背诵才丢会话。
- 重启后不恢复背诵（回到书），但记住牌组名。

## 6. 我拍的取舍

- 热键用 `Ctrl+Alt+A`（可改；和 cd/ce/cad 一样在设置里配）。
- 范围 = `deck:"<牌组>" is:due`（到期才背；你那 27,368 张新卡不进默认范围，否则第一次打开就是
  两万七千张）。Anki 自己的每日上限仍然生效——我们只是显示器，Anki 说没卡了就是没卡了。
- 牌组第一次进入时弹一个列表让你选，选完记进配置。
- 你的库是 1 笔记 : 1 卡片（29,646 : 29,646），没有 cloze 卡，所以不做 cloze 特殊处理。
- 音频进基础版（你每张卡基本都带媒体，没有音频等于背不了）。

## 8. 风险与 B 方案

- **AnkiConnect 与 Anki 26.9.3 不兼容**（装不上或加载失败）→ B 方案：只读展示（直接读
  `collection.anki2` 只读副本），评分**写不回** Anki，界面上明确标"本次不计入 SRS"。
- **`guiShowAnswer` / `guiCurrentCard` 在 Anki 最小化时不工作** → 退化成"不最小化，让 Anki
  窗口留在我们窗口后面"（我们的窗口是 `WindowStaysOnTopHint`，会盖住它），设置里给开关。
- **评分键被吞影响打字** → 只吞那 9 个键、且只在窗口可见时吞；`Ctrl+D` 收起即恢复。
- **错答风险**：评分前核对 `guiCurrentCard` 的 `cardId` 与屏幕上显示的是同一张，不一致就
  重新渲染、这一下不评分。
- **calling `guiDeckReview` 会把 Anki 窗口顶到前台一次** → 只在进入背诵时发生一次，之后我们
  把它最小化。

## 9. 验收（我要拿这些证明它好了）

1. 真机：`Ctrl+Alt+A` → 屏幕上是卡片；Anki 窗口被最小化；`Ctrl+D` 收起后我能照常打字。
2. 真机：背 3 张（1/2/3/4 各按一次），Anki 自己的统计/到期数跟着变，`U` 撤销一次也同步。
3. `Ctrl+Alt+D` 来回切，回到的还是同一张卡；`Ctrl+E` 出去看到的是书；`Esc` 回到原来那一页那一行。
4. 断网/退出 Anki/卸载插件三种情况下：给出明确提示，书页不受影响，不卡窗口。
5. 回归：安全文档、偷瞄、进度跟随、页边距/字号即时生效四条老路径的探针全绿。

## 10. 落地后的校正（以代码为准）

上面第 3–7 节是动手前的设计，实现时按实测改了几处，**以这里为准**：

- **藏 Anki 用 `SW_HIDE`（conceal），不是最小化**。实测：窗口藏起来之后 `guiCurrentCard`
  照样返回同一张卡（GUI 接口不依赖窗口可见），而隐藏的窗口不会出现在 Alt+Tab 和任务栏
  缩略图里；最小化则会留下缩略图。还原用 `SW_SHOWNOACTIVATE`，**绝不用 `SW_RESTORE`／不激活**，
  免得 Anki 突然跳到屏幕最前面。§7 里"之后我们把它最小化"那句作废。
- **吞键钩子与热键看门狗互不干扰**：`GlobalInputHook` 是独立的 `ctypes` 低级钩子，
  `keyboard.unhook_all()` 拆不到它，所以 90 秒一次的例行重挂不会影响背诵吞键。
- **安全文档可以盖在背诵上，且能原样退回那张卡**：进出用 `safe_snapshot = {"from_review": True}`
  只做标记——**绝不拍书的快照**（那会儿正文区是卡片，拍下来的是卡片坐标，退出时会把书的进度弄坏）。
  盖着的时候不吞键（屏幕上写着周报）、`render_card()` 也直接返回（对账不能把卡片画到周报上）。
- **评分键与翻面分工**：空格/回车只翻面，评分一律 1-4（Anki 里空格=良好，误按会改排程）；
  另给一条鼠标路径——点一下卡片翻面，右键菜单里有完整的翻面/评分/音频/撤销。
- **进度守卫统一成 `_book_veiled()`**（`safe_mode or review_mode`），替换了 16 处 `safe_mode`
  判断；其中两处原本会损坏数据：书页高亮被画到卡片上、在卡片上拖选会把卡片文字按卡片偏移
  写进这本书的划线存档。
- **键的捕获按"快捷键 / 交互键"分开（§4 键位那一节的重写，真人试用三轮后定稿）**。
  这两件事原来被我混成一件，试错一轮才分开：
  - **四个快捷键（老板键 / 偷瞄 / 安全文档 / 背诵）都是全局热键**（`keyboard` 库）：
    窗口不在前台、甚至藏起来了也必须能按——老板键把窗口藏起来之后它更不可能是前台窗口，
    只能靠全局热键叫回来。（中途试过把它们改成窗口内 `QShortcut`，被主人否掉，已恢复；
    `QShortcut` 现在只在"全局注册失败"时兜底，两条路绝不并存——并存时窗口是前台的那一次
    会被触发两遍，老板键会收起又立刻弹出。）
  - **卡片交互键（空格 / 回车 / 1-4 / U / R / Esc）由可见层决定归谁**，这才是主人说的
    "按 cd 和 ce 分"：`Ctrl+D` 收起 → 一个都不吞；普通显示且窗口是当前活动窗口 →
    走窗口内 `keyPressEvent`；普通显示但窗口不是活动窗口 → 不捕获；`Ctrl+E` 偷瞄 →
    全局捕获（`peek_captures_review_keys()`）。
    旧实现的判据是"背诵中 + 窗口可见 + 没最小化"，**不看焦点**——窗口摆在屏幕角落、
    人在别的软件里打字，空格和 `1-4` 会被卡片吃掉（打字时空格是最频繁的键）。
    钩子因此**只在偷瞄期间安装**，背诵本身不装任何全局钩子。
- **偷瞄不再切换内容层**：`toggle_peek()` 里"先退出背诵 / 先退出安全文档"两个前奏删除，
  `exit_peek()` 里的安全文档分支也删掉。实测四步：背诵中按 `Ctrl+E` → 还是同一张卡
  （cardId 不变）、`review_mode` 仍为真；退出偷瞄只是隐藏窗口，内容层原样不动；
  偷瞄中按 `Ctrl+Alt+D` 换成安全文档而偷瞄保持。偷瞄滚轮在卡片页只滚卡片
  （`local_start_index` 实测不变）。
- **卡片页不做书页那种底部裁切**：`apply_page_margins(cut=False)`。书页按几何切页，
  底部要"退到最后一个完整行"，否则压在窗口下沿的那行被切半；卡片页是可以滚动的，
  底边半行本来就是正常现象，照搬那套反而出事——实测一张 130px 高的短卡片被算出
  261px 的下边距，视口只剩卡片那么高（429×787 下视口 130px，窗口缩到 460 时**掉到 0**）。
- **缩放要真的重排**：`mouseMoveEvent` 的缩放分支改成 `resize()` 后再
  `repage_after_resize()`（0.05 秒节流，`mouseReleaseEvent` 里 `force=True` 补一次尾）。
  原来那条路走 `repage_to(anchor)`，而卡片页的 `local_full_text` 故意是空串，
  `repage_to` 一进门就返回——什么都没重排，`apply_page_margins()` 也没跑，
  所以底部留白一直是旧值。实测修完：707 视口 → 缩到 460 后 372，内容底 699 → 372，
  下边距 19px（页边距本身）。
- **没翻面不许评分**：评分键在偷瞄那层全局可达，`review_grade_button()` 原来只查
  card/buttons，翻面前按 1-4 会直接改排程（和 Anki 不一致）；现在先查 `shown`，
  没翻面就只给提示（探针实测：这一下**一个 Anki 请求都不发**）。
- **页脚按"工位上瞟一眼能看清"重做**：字号从写死的 11px 改成跟着字号设置走
  （`max(13, 字号 × 1.15)`，默认字号下 16px），不透明度 0.92，**整条不设底色**
  （真人反馈"这个区块不要用背景色，太显眼"——它不该看起来像个面板），按钮只留一圈
  淡描边（alpha 0.24），悬停只点亮描边不填色；并把 Anki `nextReviews` 里的
  U+2066/U+2069 方向控制符剔掉（否则渲染成豆腐块）。
- **页脚不许影响窗口尺寸**：按钮横向策略改用 `QSizePolicy.Ignored`——`Fixed` 时四个按钮的
  `minimumSizeHint`（456px）会经页脚传给 top-level，进背诵瞬间窗口从 429 被顶到 494。
  空间不够时**折行不砍字**：按**页脚真实字号**（`review_bar_font_px()`，不是
  `review_bar.fontMetrics()` 那个控件的默认 12px）量出按钮宽度，算出每行放几个
  （429 宽下是 2+2），`1 重来 <1 分` 的间隔一个字不省——真人明确说那条信息"很重要"；
  右侧提示从长到短挑第一句放得下的，且挤在最后一行末尾（不为提示多占一行正文高度）。
  缩放时只重跑 `fill_review_bar()`（文字），不重套样式表。
- **`getDeckStats` 是"一坏全坏"的**：批量里任何一个牌组查不到计数，整批报
  "Deck counts unavailable."（本机默认牌组「系统默认」就是这种）。`deck_stats()` 因此
  批量失败后退化成逐个查、跳过查不到的（设置里显示 `（计数不可用）`）——
  否则"列出牌组"按钮会整体变成"读不到牌组"。
- **藏 Anki 要能自己爬回来**：① 还原时若 `IsIconic` 仍为真（藏之前它就是最小化的），
  `SW_SHOWNOACTIVATE` 展开不了，要补 `SW_RESTORE`；② 位置体检查
  `GetWindowPlacement().rcNormalPosition`（最小化窗口的 `GetWindowRect` 是
  `@-16000,-16000` 的垃圾值），逐显示器判交集，屏幕外才搬回主屏；③ 进背诵时落
  `anki_concealed_by_us` 标记、还原成功清掉，启动时据此体检（进程被强杀也能恢复），
  托盘另有「叫回 Anki 窗口」。
